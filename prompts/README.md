# Prompts oficiais dos agentes

Os prompts desta pasta são contratos curtos. O coordenador deve montar cada pedido
usando o prompt global e o prompt da etapa. O resultado de um agente vira entrada
do próximo por meio do cartão ou relatório salvo no projeto.

Ordem: global → refinador → esforço → planejador → implementador → revisor →
testador → entrega → feedback.

O agente deve responder em português simples e informar claramente quando não tem
acesso a uma ferramenta ou a outra IA.
